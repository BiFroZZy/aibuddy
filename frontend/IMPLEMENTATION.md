# Реализация экспорта

Интерфейс перенесён в React-компоненты `src/features` и подключён к существующим контрактам `src/api`. Исходный HTML, manifest и handoff сохранены без изменений.

Визуальные стили экспорта находятся в `src/styles/server.css`; `app.css` содержит адаптации под реальные данные и доступность. SVG-спрайт собирается отдельным ресурсом для production.

Отличия от прототипа обусловлены API:

- Заявки подготавливаются в чате; нет формы и сохранённых черновиков.
- План использует фактические группы, количество шагов и `confirm_by`; самостоятельно подтверждаемые шаги не требуют наставника.
- Наставник видит только очередь ожидания, без комментариев и истории решений.
- Руководитель видит входящие заявки и может отправить необязательный комментарий; истории решений нет.
- Заявки и действия имеют отдельные вкладки и фильтры по серверным статусам; отображаются последние 50 записей.
- Метрики показывают серверные счётчики событий, инструментов и активных пользователей; фильтра по команде нет.
- Материалы направляют в чат и публичный Playbook; каталог документов не имитируется.
- Диалоги индексируются локально по ID пользователя; содержимое читается с сервера. Потерянный HTTP-ответ первого сообщения не позволяет восстановить ID диалога через текущий API; при этом подготовленные действия доступны независимо через список действий.

Проверки: Vitest/Testing Library для состояний, ошибок, повторных нажатий, смены профиля и истории; Playwright с реальными PostgreSQL, fake LLM и mock-hr для сквозных сценариев. Снимки всех основных экранов сохраняются на 8 ширинах, от 360 до 1920 px. Команды запуска приведены в `frontend/README.md`.
